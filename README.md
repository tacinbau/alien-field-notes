# Alien Field Notes

An alien tourist's one-line review of Earth, written by a small TypeScript program.

The review is a single line, well under 200 characters, with the visitor's
verdict and star rating at the end. Run `node main.ts` and it writes the
review to `/output/entry.txt`.
